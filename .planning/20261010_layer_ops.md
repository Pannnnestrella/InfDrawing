## 任务：图层基础操作（新建 / 复制粘贴 / 合并）

**背景**：图层面板 MVP 已支持列表、显隐、锁定、重命名、重排。验收时需要更接近画图软件的基础操作：新建空白层、图层间复制粘贴、合并图层。仍建立在 tldraw image shape + `shape.meta` 上，不自研合成引擎。
**影响范围**：
- `frontend/src/lib/canvas-bridge.ts` — 新建 / 复制 / 粘贴 / 合并 API

**前置条件**：
- [x] `.planning/20261010_layer_panel.md` 已落地

### Stage 1: 新建空白图层
- **目标**：在面板点「新建图层」→ 画布出现透明 PNG image shape
- **规则（推荐）**：尺寸取当前选中图片；无选中时默认 512×512；落在选中图同位或画布中心；默认名「图层 N」
- **成功标准**：新建后列表多一行，可选中、显隐、重命名
- **状态**：Complete

### Stage 2: 复制 / 粘贴
- **目标**：
  - **复制图层**：将当前选中 image 的像素 + 名称放入应用内剪贴板（不依赖系统剪贴板亦可）
  - **粘贴图层**：在锚点旁或原位偏移创建新 image shape（新 shape id，可改名「副本」）
  - **创建副本**：一键 duplicate = copy + paste
- **成功标准**：复制后粘贴得到独立图层；改粘贴层不影响源层
- **状态**：Complete

### Stage 3: 合并图层
- **目标**：将 ≥2 个选中且可见的 image 按 z-index 自底向顶合成一张 PNG，删除原层
- **合成**：浏览器 canvas 2d，尊重 opacity；对齐到包围盒
- **成功标准**：合并后列表少一层、画面视觉与叠放一致（允许抗锯齿小差）
- **状态**：Complete

### Stage 4: 面板入口与质量门禁
- **目标**：图层面板工具栏：新建 / 复制 / 粘贴 / 创建副本 / 合并；vitest + tsc；手测
- **成功标准**：相关测试通过；手测 4 条路径可用
- **状态**：Complete（自动化）；手测待用户确认
