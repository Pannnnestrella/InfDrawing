# InfDrawing 录屏 Demo 脚本

> 版本：2026-07-12 · 对应 Stage 8（阶段一收官）
> 目标：3–4 分钟成片，展示「无限画布 + 本地 AI Agent」四条功能线的端到端闭环
> 形态：本地 localhost 录屏，无需出镜；旁白可后期配音或加字幕

---

## 一、录制前准备（Checklist）

### 环境

- [ ] `.\scripts\dev.ps1 start` — 确认四项服务全部 OK（ollama / comfyui / backend / frontend）
- [ ] 先在侧栏跑一次生图**热身**：首次推理要加载模型到显存，正式录制时速度会明显更快
- [ ] 关闭无关软件，释放显存（目标 free ≥ 7GB，可看 `/api/v1/system/capabilities`）
- [ ] 浏览器：无痕窗口打开 `http://127.0.0.1:3000`，隐藏书签栏，缩放 100%
- [ ] 系统：关闭通知（Win+N → 勿扰模式），隐藏任务栏或全屏录制窗口

### 素材（提前准备，放桌面）

- [ ] **拆解用图**：主体清晰、背景简单的图（如白底商品图、单人照）——rembg 效果最稳
- [ ] **文字编辑用图**：印刷体、字号较大的海报/标语图——EasyOCR 对手写和小字易漏检
- [ ] **备份成品**：每个环节提前跑一次并保留结果截图，正式录制翻车时可剪辑替换

### 录制设置

- [ ] 分辨率 1920×1080，30fps；OBS 或 Xbox Game Bar（Win+Alt+R）
- [ ] 鼠标指针高亮（OBS 可加指针特效），方便观众跟随操作

## 二、分镜脚本

> 时间为**成片时间**；SD1.5 实际生成约 20–40 秒/张，录制时正常等待，后期把等待段加速或跳剪，只保留进度条起始和完成瞬间。

### 场景 0 — 开场（0:00–0:20）

| 项 | 内容 |
|---|---|
| 画面 | 空画布全貌 → 缓慢缩放/平移展示无限画布 → 鼠标划过侧栏四个模式按钮 |
| 操作 | 滚轮缩放、空格拖拽平移；随手画两笔展示 tldraw 基础绘制 |
| 旁白 | 「InfDrawing 是一个本地运行的 AI 无限画布：前端 tldraw，后端 FastAPI 编排 Ollama 和 ComfyUI，全程不依赖云端 API。侧栏提供四种 AI 能力：生图、局部重绘、元素拆解和文字编辑。」 |

### 场景 1 — 侧栏对话生图（0:20–1:00）

| 项 | 内容 |
|---|---|
| 操作 | 点侧栏 **[生图]** → 输入 prompt → 发送 → 展示进度推送 → 生成图自动落到画布 |
| Prompt | `a cozy wooden cabin in a snowy forest, warm light from windows, digital painting` |
| 镜头重点 | ① 消息流里的状态更新（WebSocket 实时进度）② 图片自动回贴画布并可拖拽缩放 |
| 旁白 | 「在侧栏输入描述，后端把任务提交给本地 ComfyUI 的 SD1.5 工作流，进度通过 WebSocket 实时推送——即使断线也会自动重连并补发最后状态。生成完成后图片直接落到画布上，成为可编辑的元素。」 |

### 场景 2 — 局部重绘 Inpaint（1:00–1:45）

| 项 | 内容 |
|---|---|
| 操作 | 选中场景 1 的小屋图 → 点 **[局部重绘]** → 用 Mask 笔刷刷选天空区域 → 输入 prompt → 生成 → 新图回贴 |
| Prompt | `northern lights, aurora borealis in the night sky` |
| 镜头重点 | ① Mask 笔刷的刷选过程（放慢操作）② 重绘前后对比（可并排放置两张图） |
| 旁白 | 「选中画布上的任意图片，用笔刷标记想修改的区域，其余部分保持不变。这里把天空换成极光——蒙版和原图由前端导出后交给 inpaint 工作流处理。」 |

### 场景 3 — 右键快捷生图（1:45–2:05）

| 项 | 内容 |
|---|---|
| 操作 | 在画布空白处**右键** → 选「AI 生图」→ 弹出浮层输入短 prompt → 生成在右键位置 |
| Prompt | `a red fox sitting in snow, digital painting` |
| 旁白 | 「除了侧栏，画布任意位置右键即可就地生成，图片会出现在你点击的位置——保持创作时的空间感。」 |

### 场景 4 — 元素拆解（2:05–2:45）

| 项 | 内容 |
|---|---|
| 操作 | 拖入准备好的商品/人物图 → 选中 → 侧栏 **[元素拆解]**（或右键菜单）→ 生成前景/背景两个图层 → 分别拖动两个图层展示已分离 |
| 镜头重点 | 拆解后**把前景图层拖开**，露出补全后的背景——这是最直观的「哇」时刻，放慢操作 |
| 旁白 | 「元素拆解用 rembg 分离前景，再用 inpaint 补全被遮挡的背景，得到两个独立图层。前景可以单独移动、复用到其他构图里。」 |

### 场景 5 — 文字编辑（2:45–3:25）

| 项 | 内容 |
|---|---|
| 操作 | 拖入海报图 → 侧栏 **[文字编辑]** → OCR 检测出文字区域 → 点选要改的区域 → 输入新文字 → 生成：原字被抹除、新文字以矢量叠加 |
| 镜头重点 | ① OCR 框选中的高亮 ② 完成后**双击新文字直接再编辑**（矢量文字，非像素） |
| 旁白 | 「文字编辑先用 EasyOCR 定位文字，再用 inpaint 抹除原字，最后以 tldraw 矢量文字叠加——所以改完的文字仍然可以随时二次编辑。」 |

### 场景 6 — 收尾（3:25–3:50）

| 项 | 内容 |
|---|---|
| 画面 | 缩小到画布全貌，展示本次 demo 产生的所有元素 → 快速切到 `http://127.0.0.1:8000/docs` 的 Swagger 页面一瞥 → 回到画布定格 |
| 旁白 | 「以上全部运行在一台 8GB 显存的笔记本上：Ollama 负责意图解析，ComfyUI 负责图像工作流，FastAPI 统一编排。阶段二计划接入云端 Flux 和 AnyText2，进一步提升生成质量。谢谢观看。」 |

## 三、剪辑要点

1. **等待段处理**：每次生成保留「提交 + 进度条开始」约 2 秒 → 4–8 倍速快进 → 完成瞬间回到常速。全片不要出现超过 3 秒的静止等待。
2. **对比呈现**：inpaint 和文字编辑务必有前后对比镜头（并排或快速切换）。
3. **字幕**：旁白若不配音，用底部字幕替代；关键术语（SD1.5 / rembg / EasyOCR / WebSocket）在画面角落用小标签标注。
4. **诚实标注**：片尾或简介注明「本地 SD1.5 + 8GB VRAM，生成质量与速度受硬件限制」——效果边界见 `进度.md` §已知效果边界。

## 四、翻车预案

| 风险 | 预案 |
|------|------|
| 生成质量差（SD1.5 抽卡） | 每个场景录 2–3 条，选最好的一条；prompt 用上表验证过的措辞 |
| OCR 漏检 | 换备用海报图（印刷体大字）；或直接用预先验证过能检出的那张 |
| 拆解边缘毛糙 | 选白底/纯色背景素材；演示时不要过度放大边缘 |
| 服务中途挂掉 | `.\scripts\dev.ps1 restart`；分场景录制，单场景重录成本低 |
| 显存不足变慢 | 录制前 `dev.ps1 status` 确认；两次生成之间留 10 秒喘息 |
