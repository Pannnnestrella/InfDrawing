## 你还需要自己做的 4 件事

1. **封面信息**：学校 / 姓名 / 联系方式（见 `00` 占位）。
2. **补截图**：见 `03` 清单。现有 Word 只有画布全貌和素材库面板，多轮编辑窗口还没有图。
3. **录屏（强烈建议）**：按 `05` 录 3 分钟，链接写进 PDF 开头。
4. **代码可见性**：GitHub `origin/main` 目前仍是早期画布提交，**素材库与多轮编辑尚未 push**。若把仓库当补充材料，需要先提交并推送；否则写「随 PDF 附源码压缩包」或私有仓库邀请，不要只贴现在的 public URL。

## 叙事一句（全文主线）

InfDrawing 是我自己用的 AI 画布。用它做游戏概念图时，真正卡住生产的不是「会不会生图」，而是：**生成物找不到、改完对不上、历史回不去**。本作业把这两件事做成可运行原型：VLM 标注入库，以及带实体锁定与修改树的多轮编辑。
