# 录屏脚本（约 3 分钟）

目的：补充材料第 2、3 项。成片只演示作业核心，不重演全部 Lovart 功能。

准备：无痕窗口打开 `http://127.0.0.1:3000`，画布上已有骑士整图；素材库里最好已有 1–2 条旧资产，方便对比「新条目出现」。关闭 Next.js 调试框。生成等待段后期 4–8 倍速。

| 时间 | 画面 | 操作 | 可配的一句旁白 |
|---|---|---|---|
| 0:00–0:15 | 画布全貌 | 缩放、拖开一张拆解前景 | 「我用自己做的 AI 画布画游戏概念图。出图很快，随后有两件事反复卡住：图找不到，改完对不上。」 |
| 0:15–0:50 | 右键菜单 → 入库对话框 → 素材库面板 | 对女剑士前景「加入素材库」，等标注，面板跳到新条目 | 「选中图层交给视觉模型写类型、视角、物件和描述。人只改错的字段。拆解后的角色和风景分成两条资产。」 |
| 0:50–1:10 | 搜索框 | 输入「长剑」或「女剑士」，点「贴回画布」 | 「搜索走标注文本，不靠文件名。」 |
| 1:10–1:35 | 多轮编辑窗口 | 从画布选中整图打开，展示实体树，锁定脸 | 「改图时先告诉系统哪些实体不能动。Preserve 列表由程序生成。」 |
| 1:35–2:20 | A 线一轮 | 「把剑换成火焰弯刀」，快进等待，滑块对比 | 「只改剑。脸由锁定参考图锚定，本轮写入修改树。」 |
| 2:20–2:50 | 树上看分支 | 点回根节点，说明 B 线是发型/帽子/背景 | 「回退是切指针。从中间节点可以开第二条产品线，不用另存文件。」 |
| 2:50–3:10 | 定格：树 + 库 | 缩小到同时能看到画布、树、库 | 「生成物进入素材库，改图进入版本树。这是我在内容生产里真正补上的两环。」 |

不要在成片里：ComfyUI 窗口、Swagger、终端、失败重试转圈超过 3 秒静帧、手套金线那种「几乎没变化」的轮次。
