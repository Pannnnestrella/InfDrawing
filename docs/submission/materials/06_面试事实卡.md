## 模块一 素材库

| 项 | 值 |
|---|---|
| 后端包 | `backend/app/assets/` |
| 前端 | `frontend/src/library/`，右键 `AiContextMenu` |
| HTTP | `/api/v1/assets/libraries`、`/items`、`/artifacts/{id}` |
| capabilities | `features.asset_library` |
| 索引文件 | `data/assets/library.json` |
| 标注模型 | `scene_vision_client()`，默认 qwen3-vl-plus |
| 检索 | `search_blob` 子串，无 embedding |
| 闭合字段 | 类型 / 视角 / 题材 / 背景 / 姿态 + 主色 / 材质 |
| 失败策略 | `caption_failed` 仍保存图像 |
| 明确未做 | 形状搜索、向量库、质量 QC、多人权限 |

## 模块二 多轮编辑

| 项 | 值 |
|---|---|
| 后端包 | `backend/app/controlled_edit/` |
| 前端 | 首页可拖动窗口；`/studio` 重定向到首页 |
| HTTP | `/api/v1/controlled-edit/sessions`、`/turns`、实体 status/bbox、checkout、删版本 |
| scope | `controlled_edit` |
| 定位 | Qwen-VL `xyxy_1000` |
| 改图 | 默认 qwen-image-edit-plus；小物件 wanx mask |
| 验收 | 几何构图检查 + gpt-4o；锁定实体有效分 = min(相对上一帧, 相对锚点 crop) |
| 重试 | 默认 1 次，失败原因写回 prompt |
| 持久化 | `data/cedit/sessions.json` 与 artifacts 索引 |
| 硬贴回 | `INFD_CEDIT_LOCK_PASTE` 默认 false |
| 明确未做 | 像素级生产审核、多人实时锁图、把验收当生成器 |

## 底座（第 1 节可以提，不要当成作业新做的）

生图 / inpaint / 拆解 / 文字编辑；拆解现可走通义改图分层（前景 RGBA + 补背景）。这些用来产生库里的碎片和进入改图的原图。

## 被问到「核心验证单元」时怎么答

两句：

1. 素材库：一张拆解前景从画布进入命名库，VLM 字段可被关键词找回并贴回。
2. 多轮编辑：锁定脸之后，从同一根节点走出装备线和外观/场景线，树还在、脸还在。

## 被问到效果边界时主动说

- 验收分数偏松，所以加了几何构图检查；纹理脏了要靠分支回退。
- mask 不适合细金线。
- 分组框偏大，脸/剑/盾的框才用来点选。
- 这是作者本机原型，不是资产中台。
